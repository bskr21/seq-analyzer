# v0.8.0-alpha — Separate ANALYZE and BUILD

This development branch contains a read-only ANALYZE flow in `device/Sequencer Analyzer.maxpat`,
`device/aicb_live.js`, and `device/aicb_node.js`.

## Important: installer still points to the old AMXD

The bundled `device/Sequencer Analyzer.amxd` is **not regenerated** in this alpha.
`setup.command` still installs that old AMXD; running the installer by itself will
**not** install the new buttons.

To try the alpha UI in Max for Live:
1. Work on a copy of your Live Set, not a performance set.
2. Make sure the Python engine and Max JavaScript dependencies are already installed.
3. Open the development `.maxpat` in Max (from the `device` folder, keeping both JavaScript files alongside it).
4. Adapt/save the patch as a Max Audio Effect in Live before using it as a device.
   The exact packaging step and Live compatibility are not yet validated.
5. Click ANALYZE. The result appears in the status field; detailed lines appear in Max Console.
6. BUILD (beta) intentionally only displays a message and changes nothing.

ANALYZE ignores clips shorter than 30 seconds and reads up to 16 clips on its track.
It reports filename, BPM, audio duration, arrangement start beat, and Warp ON/OFF
in Max Console. It does not alter song tempo, warp, or arrangement.

## Incomplete and untested

- Regeneration of the deployable `.amxd` file
- Tested UI loading in Live 12.3.2
- In-device tabular list (currently status line + Max Console)
- Reliable processing of failed songs and changing clips between analyze and build
- BUILD through the experimentally validated Python WarpMarker API
- Multi-song overlapping clip protection, guide cues, and manual Lead reminder

The legacy `build()` implementation remains in the JavaScript file for reference
but is not wired to the alpha buttons.
