# Sequencer Analyzer v0.8.0-alpha — ANALYZE test kit

## Download the alpha device

1. In GitHub, open **Actions** → **Package Sequencer Analyzer alpha**.
2. Select the newest successful workflow run on branch `feature/separate-analyze-build`.
3. Download the `seq-analyzer-v0.8.0-alpha` artifact and unzip it.
4. The package should contain `Sequencer Analyzer v0.8.0-alpha.amxd`, `aicb_live.js`, `aicb_node.js`, and `aicb_progress.js`.

Workflow success only verifies packaging, not compatibility with Ableton Live.

## Test in Ableton Live 12.3.2

1. Work on a COPY of your Live Set.
2. Ensure your existing analysis engine was previously installed with `setup.command` (if needed, run the old installer BEFORE installing alpha).
3. Do NOT rerun `setup.command` afterward: it still installs the old v0.7.1 device.
4. Keep all four alpha files in their own folder, separate from the old device, and drag the alpha AMXD onto the audio track.
5. Place one or two audio clips longer than 30 seconds on that track.
6. Press **ANALYZE**. Read the summary in the device status field and the complete list in **Max Console**.
7. Compare the original clip Warp state, BPM, length and track count before and after analysis. They should NOT change.
8. Press **BUILD (beta)**. It should display a disabled-feature notice and must not edit the Arrangement.

If the device will not load, report the Max Console error and keep using the old device.

## Intended alpha output

Each analyzed clip reports filename, detected BPM, duration in seconds, arrangement starting beat, and Warp ON/OFF. ANALYZE does not require the cue pack to be selected; BUILD is intentionally inactive.

## Current limitations

- The in-device table is not built yet; results appear in a status summary and the Max Console.
- The AMXD is generated by replacing the patch payload in the checked-in device container and has NOT been opened in Live for validation.
- This alpha does not write Warp Markers, tempo automation, SECTION clips or GUIDE CUES.
- Lead must eventually be enabled manually after BUILD, in later beta.
- Error recovery, clip changes between Analyze and Build, and edge cases still require testing.

Report back whether the AMXD loads, the ANALYZE result, any console errors, and whether Warp and clip lengths remain unchanged.
