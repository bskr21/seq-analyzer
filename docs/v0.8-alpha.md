# Sequencer Analyzer v0.8.0-alpha.5 — UI Redesign Test

## Download

1. Open **GitHub Actions** → **Package Sequencer Analyzer alpha**.
2. Select the latest successful run for `feature/separate-analyze-build`.
3. Download artifact `seq-analyzer-v0.8.0-alpha` and unzip it.

The bundle contains `Sequencer Analyzer v0.8.0-alpha.amxd`, `aicb_live.js`, `aicb_node.js`, and `aicb_progress.js`. The AMXD filename is the same as earlier alpha builds; use the newest workflow run and replace all companion files together.

## UI Changes

- Native Max `live.tab` selector: **SETUP / ANALYZE / BUILD**
- SETUP: cue folder selector, dynamically named for selected folder
- ANALYZE: read-only BPM scanning and a **Show Song List / Hide Song List** control
- Native Max `jit.cellblock` scrollable results: full clip name, BPM, audio duration, bar position, Warp ON/OFF; up to 16 songs
- BUILD: disabled placeholder. Lead remains manual in future beta.

## First test in Live 12.3.2

Use a COPY of a Live Set. Do not run the original installer after unpacking the alpha.

1. Keep the four alpha files in the same folder and drag the AMXD into an audio track.
2. Check that the three tabs appear and switching tabs changes the contents.
3. In SETUP, select the **English Guides** folder. Check the button label and orange selected background.
4. In ANALYZE, scan four songs. Check **ANALYZE: 4/4** and Show Song List.
5. Inspect all four entries by scrolling vertically (and horizontally to inspect full long titles and details).
6. Toggle Hide Song List, then Show Song List, and switch tabs away and back.
7. Confirm that clip Warp, length, position, and BPM remain unchanged after ANALYZE.
8. In BUILD, confirm there is no editing action.

## Caveats

- GitHub Action success means packaging succeeded, **not** that Max or Live successfully rendered the device.
- The AMXD has not been validated inside Live 12.3.2 by the developer.
- Position formatting assumes a constant global time signature. Time-signature changes need a dedicated resolver.
- The new tab hiding and Jitter table are experimental and must be tested in Live.
- BUILD / WarpMarker integration intentionally is not active in this alpha.
